# Соседи — автоматический конвейер шортсов

Каждый день сам: ищет тренды → пишет серию → критик проверяет сценарий →
генерирует видео с постоянными персонажами → монтирует → загружает на YouTube →
присылает готовое видео в Telegram.

Полная пошаговая инструкция по настройке — в документе «Соседи: инструкция
по автоматическому конвейеру».

## Файлы
- `config.yaml` — все настройки (язык, длина, пауза, персонажи).
- `bible.md` — библия сериала, по ней пишет сценарист.
- `characters/` — эталонные картинки героев (создаются автоматически).
- `data/history.json` — список вышедших серий (чтобы не повторяться).
- `pipeline/` — код агентов.
- `.github/workflows/daily.yml` — расписание запуска.

## Ручной запуск
GitHub → вкладка **Actions** → **Neighbors daily episode** → **Run workflow** →
выбрать режим:
- `test` — проверка без затрат (цветные заглушки вместо видео);
- `refs` — создать недостающие эталоны персонажей;
- `refs-all` — пересоздать все эталоны;
- `daily` — выпустить серию прямо сейчас.

## Секреты (Settings → Secrets and variables → Actions)
`GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (необязательно),
`YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`.
